# Scenario-specific comparison with Claude Code

The motivating, anonymized field scenario involved an application built with
Claude assistance whose team then sought independent release validation.
Claude Code and GitHub Copilot can both edit code, use MCP-based tools, and
participate in GitHub workflows; AgentProof does not claim superior code
generation or that Claude cannot implement a comparable workflow. Its narrower,
demonstrated Copilot App advantage is fewer lifecycle seams for this scenario:
three isolated specialist sessions, repository context, a reusable plugin and
mutable canvas, remediation, PR checks, reviews, and repository rules appear in
one GitHub-centered workspace. A manual Evidence Assembler remains explicit.
Deterministic collectors—not model judgment—compute `AgentProof / gate`, and a
different human still approves. The Claude-assisted PR is classified
`self-declared` unless verified platform attribution exists, and is governed on
the same terms as Copilot-assisted, local-model, or human-written code. This is
a scenario proof, not a universal product, provenance, compliance, security, or
code-quality claim.
