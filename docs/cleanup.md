# Removing an AgentProof integration

Retire only the named integration in `<OWNER>/<REPO>` with the repository owner's
approval. Local removal does not delete App sessions, personal automations, or
remote evidence. Preserve authorized work and records under the applicable
retention policy.

## Copilot App

Inspect each owner's actual inventory. Disable any unsafe candidate, then remove
only obsolete approved configurations; do not assume the template files created
automations. Close unneeded reviewer/assembler sessions and uninstall the plugin
when no longer needed. Clear mutable Evidence Board state separately from GitHub
records and remove outdated deep links.

## Consuming repository

Review removal of the four installed AgentProof workflows, shared scripts,
policy, and evidence packages. Update root workspaces, package scripts, lockfile,
ownership rules, and documentation together. Keep the application's source and
its own build/test controls.

Do not leave a production branch weaker than its approved baseline. Replace
required-check enforcement under an approved change process before retiring its
publisher. Remove temporary access, bypasses, and disposable PR branches only
with appropriate authorization. Do not merge unsafe validation changes.

Actions artifacts and logs have finite retention, not immediate deletion.
Use GitHub's supported retention/removal process when required and preserve
approved audit references. Investigate any unexpectedly provisioned secrets
without exposing their values.

## Local files and verification

Remove only specifically identified temporary checkouts, generated evidence,
and fixture output after preserving authorized work. Never delete shared
Node/npm caches or a broad workspace root as an integration cleanup step.

Confirm no enabled automation unintentionally targets the retired integration,
no stale required check or bypass remains, and no unneeded temporary access
persists. Clearing the board or deleting a clone does not revoke previously
downloaded artifacts. Removal does not change the meaning of historical evidence
or turn scanner/reviewer output into a legal or compliance determination.
