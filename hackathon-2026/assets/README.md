# Submission media assets

This directory contains generated, sanitized media aids for the recording
workflow.

- `agentproof-silent-draft.mp4` is a silent, precomputed timing draft. It is
  not live evidence and carries a persistent `PRECOMPUTED / NOT LIVE` banner.
- `agentproof-silent-draft.srt` contains the matching cue-card captions.
- `agentproof-shot-log.template.md` is copied into a final shot log after the
  live take.

Replace the draft with the live GitHub/App recording before submission. Keep
the draft only as a clearly labeled editing reference.
