# AgentProof submission video script

**Runtime:** 2 minutes 44 seconds.  
**Official maximum:** 3 minutes.  
**Label:** `STAGED DEMO | SYNTHETIC DATA`.

The video uses a validated GitHub record from the synthetic AgentProof
repository and staged visuals generated from the repository's evidence
contract. It never presents a fabricated approval, exception, merge, release,
customer quote, or compliance determination.

## Scene 1 - 0:00-0:18 - The customer question

**On screen:** AI-assisted pull request, exact SHA, release-lead question.

**Narration**

> Enterprise customers are not asking whether AI can write code. They are
> asking a harder question: can we prove that this exact change is ready to
> ship, under our policy, with a human still accountable?

## Scene 2 - 0:18-0:38 - Real enterprise signal

**On screen:** anonymized research counts: 2 direct cases, 9 adjacent
AI-governance accounts, 5 traceability/legal-compliance accounts.

**Narration**

> That need is real. Our approved internal research found direct
> release-validation cases, broader AI-governance signals, and repeated demand
> for traceable evidence. AgentProof turns that customer ask into a reusable
> GitHub Copilot App workflow without exposing customer data.

## Scene 3 - 0:38-1:00 - The workflow

**On screen:** pull request to deterministic collection, protected-base policy,
read-only specialist sessions, Evidence Board, human decision.

**Narration**

> A pull request starts no-secret collectors for tests, dependencies, data
> handling, and origin. Policy comes from the protected base, so the proposed
> change cannot weaken its own rules. Read-only Copilot specialists explain the
> same commit-bound facts. The Evidence Board Canvas turns them into one
> release-control surface.

## Scene 4 - 1:00-1:22 - Validated proof

**On screen:** the live Evidence Board Canvas for PR #2, full SHA
`502aaf17d7a49c73c2c0bfef76aff2f69dc9ead3`, protected policy, gate summary,
and distinct finding states.

**Narration**

> Here is the Canvas opened on validated synthetic pull request number two. It
> binds the full head SHA, protected policy, five passes, and one unknown in one
> view. Missing retention evidence is not silently converted into a pass. One
> unresolved fact keeps the release blocked.

## Scene 5 - 1:22-1:45 - Human accountability

**On screen:** an unresolved finding selected in the Canvas, the exact
SHA-bound draft command, stale prior dispositions, and the GitHub authority
boundary.

**Narration**

> A reviewer selects the unresolved finding, and the Canvas drafts an exact
> full-SHA command. It still does not approve anything. Only an eligible human
> can submit that decision in GitHub. When code changes, earlier evidence and
> dispositions become stale. Agents can propose; they cannot approve, merge, or
> release.

## Scene 6 - 1:45-2:05 - Repeatable field kit

**On screen:** plugin, agents, skills, canvas, policy, setup, templates, success
measures.

**Narration**

> This is a field kit, not a one-off demo: four agent profiles, two reusable
> skills, an Evidence Board canvas, policy and evidence schemas, GitHub Actions,
> setup templates, threat modeling, and measurable adoption steps. Account
> teams can adapt the pattern without copying customer data.

## Scene 7 - 2:05-2:25 - Competitive differentiation

**On screen:** Claude Code and GitHub Copilot both edit and use tools; only the
AgentProof side shows the GitHub-native governed control loop.

**Narration**

> Claude Code and Copilot can both edit code and use connected tools. Our
> differentiation is not a model-quality claim. It is the demonstrated
> GitHub-native handoff across repository context, checks, artifacts, comments,
> reviews, rules, specialist agents, and a human decision surface.

## Scene 8 - 2:25-2:44 - Product feedback and close

**On screen:** permission canary, runtime mismatch, fail-closed result, closing
message.

**Narration**

> We also tested automation permissions. Even after selecting read-only tools,
> the runtime exposed mutation-capable tools, so the canary failed closed and we
> disabled it. That is our product feedback and our design principle: agents
> accelerate the work; current evidence and accountable humans decide what
> ships.
