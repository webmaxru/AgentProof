# AgentProof hackathon submission

The complete FY27 GitHub Copilot App Enterprise Challenge package is in
[`hackathon-2026/`](../hackathon-2026/README.md).

## One-sentence value proposition

AgentProof gives enterprise release leads one commit-bound evidence and human
decision workflow for AI-assisted pull requests while keeping GitHub checks,
reviews, and repository rules authoritative.

## The customer-real scenario

Enterprise customers want AI-assisted development without losing the ability
to answer four release questions:

1. Which exact commit was evaluated?
2. Which policy version applied?
3. What is pass, fail, unknown, or accepted exception?
4. Which accountable human decision is still required?

An approved internal research pack found two direct release-validation cases,
adjacent AI-governance evidence across nine accounts, and traceable
legal/compliance evidence needs across five accounts. The counts support the
problem statement; they are not customer endorsements of AgentProof.

## Why AgentProof is memorable

The change cannot choose its own policy, and an old decision cannot silently
follow new code.

Deterministic collectors gather facts without secrets. Protected-base policy
evaluates them. Read-only Copilot specialists explain the same full-SHA
evidence. The Evidence Board makes the result readable. Authorized humans
retain exception and approval authority. GitHub remains the auditable record
and enforcement boundary.

## Submission assets

- official rules and weighted scoring;
- a copy-ready summary under 150 words;
- a narrated staged demo under 3 minutes;
- timed captions;
- an eight-slide PowerPoint deck;
- eight full-resolution stills;
- a rubric-to-proof matrix;
- copy-ready product feedback for the bonus;
- reproducible media/deck generators; and
- the product repository, setup, governance, tests, prompts, templates, and
  canvas extension.

AgentProof produces evidence. It does not make a legal, compliance, privacy, or
security determination.
